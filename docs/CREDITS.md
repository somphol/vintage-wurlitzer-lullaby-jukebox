# Credits

## Build

- **Tool:** [OpenCode](https://opencode.ai)
- **Model:** DeepSeek V4.1 Flash (`opencode-go/deepseek-v4.1-flash`)
- **Session:** one continuous build — concept, 3D cabinet, audio engines, bilingual UI, tests, docs,
  deployment and the reusable skill.
- **Record:** elapsed time and token counters are captured in [state.json](../state.json) from the
  OpenCode session database. Cache reads dominate the token total; cost is zero on the flat-rate plan.

## Engineering

- [Three.js](https://threejs.org/) 0.169.0 — MIT. Renderer, OrbitControls, RoomEnvironment,
  EffectComposer, UnrealBloomPass, OutputPass.
- Web Audio API — platform.
- No npm packages, no fonts, no analytics.

## Music and recordings

The 50 procedural arrangements are original settings of public-domain melodies, plus 18 original
compositions. The public-domain sources include (the full 50-track catalogue is in [TRACKS](TRACKS.md)):

- Johannes Brahms, *Wiegenlied* (1868)
- *Twinkle, Twinkle, Little Star* (Jane Taylor, 1806)
- *Schlafe, mein Prinzchen* (attr. Bernhard Flies, 1795; formerly attributed to Mozart)
- Franz Schubert, *Wiegenlied* (1816)
- *Rock-a-bye Baby* (traditional)
- *Hush, Little Baby* (traditional)
- *Frère Jacques* (traditional French)
- *Golden Slumbers* (traditional English)

The four archive streams are **linked, not redistributed**. Each is marked **Public domain** on its
Wikimedia Commons page:

- Brahms – Schumann-Heink, *Wiegenlied* (1915)
- *Lullaby Wound-Up Clock*
- Gabriel Fauré, *Berceuse* Op. 56 No. 1
- Christian Cappelen, *Berceuse*
