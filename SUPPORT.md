# Support

This is a hobby release maintained on a best-effort basis.

## Try these first

1. Read the [FAQ](docs/FAQ.md).
2. Open `?selftest` and check the pass/fail list.
3. Run `node --test tests/engine.test.mjs tests/static.test.mjs` and `node tests/browser.test.mjs`.
4. Confirm the Three.js CDN and Wikimedia are reachable; both are network dependencies.

## Ask a question

- Use the **Question** issue template.
- Include browser and OS versions, the URL, whether `?selftest` passes, and any console output.
- Do not paste tokens, personal data or private links.

## Request a feature

Use the **Feature request** template. Say which of the three layers it touches (3D cabinet, audio
engine, sleep UI) and whether it preserves the zero-build, no-backend constraint.

## Security

Please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
